# org-profile

The GitHub organization's profile page, published to [Chameloon-Labs/.github](https://github.com/Chameloon-Labs/.github):
`git subtree push --prefix=org-profile github-profile main`. GitHub shows `profile/README.md` onhttps://github.com/Chameloon-Labs.

The pictures are drawn like the website: `python3 brand/org-profile.py` in the main repo.
